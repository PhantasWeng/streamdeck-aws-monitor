Instance ID: enter i-xxxxxxxx, or use debug for simulation mode (no credentials required).

Metrics: CPU is a native EC2 metric. Memory and disk usage require the CloudWatch Agent on the instance; without it, the button shows CPU only.

Display Mode: All metrics shows the current CPU/memory/disk bars. Picking a single metric draws a chart of the last 2.5 hours instead (5-minute resolution, ~30 points). The chart shows NO DATA when the metric is unavailable — most often memory or disk without the CloudWatch Agent.

IAM permissions: ec2:DescribeInstances, ec2:DescribeInstanceStatus, cloudwatch:GetMetricData.

Actions: single press to refresh; double-press to open CloudWatch metrics; long press to open the EC2 Console.
